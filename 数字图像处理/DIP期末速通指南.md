## 第1天：基础概念 + 空间滤波（最重要，约30%分值）

### 1.1 图像基础

**存储计算**（必考）：
- 灰度图像存储 = 宽 × 高 × 灰度级位数
- 例：256×256 图像，256灰度级（=8bit）= 256×256×8 = 524,288 bits = 512 Kbits = 64 KB
- 注意题目问的是 **bits** 还是 **bytes**！（1 byte = 8 bits）

**像素间距离**（必考）：
- **欧几里得距离 (Euclidean/D2)**：√[(x1-x2)² + (y1-y2)²]
- **城市街区距离 (City-block/D4)**：|x1-x2| + |y1-y2|
- **棋盘距离 (Chessboard/D8)**：max(|x1-x2|, |y1-y2|)

**图像处理三层次**：
- 低级 (Low-level)：去噪、增强、平滑/锐化
- 中级 (Mid-level)：图像分割、特征提取 ← 重点区分
- 高级 (High-level)：图像理解、识别

### 1.2 空间滤波 (Spatial Filtering)

**平滑滤波器 (Smoothing) — 模糊/去噪**：
| 滤波器 | 公式 | 用途 |
|--------|------|------|
| 均值滤波 (Average/Mean) | 邻域平均值 | 平滑、去噪 |
| 加权平均 (Weighted Average) | Σw_i·z_i / Σw_i | 中心权重更大的平滑 |
| 中值滤波 (Median) | 邻域中值 | 去椒盐噪声效果最好 |
| 中点滤波 (Midpoint) | (max+min)/2 | 去高斯+均匀噪声 |

**锐化滤波器 (Sharpening) — 突出边缘**：

一阶导数算子（梯度算子）：
- **Sobel 算子**：
  - 水平边缘：[[-1,-2,-1],[0,0,0],[1,2,1]]
  - 垂直边缘：[[-1,0,1],[-2,0,2],[-1,0,1]]
  - 特点：边缘清晰但粗略
- **Prewitt 算子**：
  - 水平边缘：[[-1,-1,-1],[0,0,0],[1,1,1]]
  - 垂直边缘：[[-1,0,1],[-1,0,1],[-1,0,1]]
  - 与Sobel比：有一定抗干扰性，图像效果比较干净
- **Roberts 交叉算子**：2×2小模板

二阶导数算子：
- **Laplacian 算子**：
  - 标准模板：[[0,1,0],[1,-4,1],[0,1,0]]
  - 变体：[[1,1,1],[1,-8,1],[1,1,1]]
  - 锐化结果：g(x,y) = f(x,y) - ∇²f(x,y)
  - 复合模板：[[0,-1,0],[-1,5,-1],[0,-1,0]]
  - 特点：边界细致，包含细节信息

**Sobel vs Laplacian 对比**（常考）：
- Sobel：一阶导数，边界粗略但清晰，反映边界信息较少
- Laplacian：二阶导数，边界细致，包含细节信息多但边界不太清晰
- 梯度算子：边缘处一阶导极大值，对噪声敏感
- Laplacian：边缘处二阶导过零点

### 1.3 灰度变换 (Intensity Transformation)

**分段线性变换**（必考计算题）：
- 题目给出原范围→新范围的映射，写出变换函数
- 例如：[0,20]→[0,30], [20,30]→[30,50], [30,60]→[50,60]
- 公式：f(x) = (新范围斜率)(x - 原起点) + 新起点

**题型示例**（来自真题A第6题）：
```
[0:20]→[0:40]: f(x) = 2x
[20:50]→[40:80]: f(x) = (40/30)x + 40/3 = 4/3·x + 40/3
[50:100]→[80:100]: f(x) = (20/50)x + 60 = 2/5·x + 60
```

## 第2天：频率域滤波 + 傅里叶变换（约20%分值）

### 2.1 傅里叶变换基础

**核心概念**：
- 任何周期函数可以表示为不同频率的正弦和余弦之和（Fourier series）
- DFT将空间域图像变换到频率域
- 频谱图中间是低频，越靠外频率越高
- 图像能量主要集中在低频区，高频能量很少

**DFT公式**（需要认识，不一定要背）：
F(u,v) = ΣΣ f(x,y)·e^(-j2π(ux/M+vy/N))

**平移性质**（真题考过证明，8分）：
f(x,y)·e^(j2π(u₀x/M+v₀y/N)) ⇔ F(u-u₀, v-v₀)

证明思路：
F[f(x,y)·e^(j2π(u₀x/M+v₀y/N))] 
= ΣΣ f(x,y)·e^(j2π(u₀x/M+v₀y/N)) · e^(-j2π(ux/M+vy/N))
= ΣΣ f(x,y)·e^(-j2π((u-u₀)x/M+(v-v₀)y/N))
= F(u-u₀, v-v₀)

### 2.2 频率域滤波器

**低通滤波器 (Lowpass)** — 平滑/模糊：
- **理想低通 (ILPF)**：圆内全通过，圆外全截断 → 有振铃效应
- **Butterworth低通 (BLPF)**：平滑过渡，n阶
- **高斯低通 (GLPF)**：最平滑，无振铃

**高通滤波器 (Highpass)** — 锐化/边缘提取：
- 低频对应平滑区域，高频对应边缘和突变
- 判断题常考："低频成分对应边缘" → **错**（高频对应边缘）

**记住**：
- 低通滤波 = 平滑 = 去噪 = 模糊
- 高通滤波 = 锐化 = 边缘增强 = 提取细节
- 空间域平滑 = 频率域低通
- 空间域锐化 = 频率域高通

## 第3天：直方图 + 插值 + 图像分割（约25%分值）

### 3.1 直方图均衡化 (Histogram Equalization)（必考计算大题，10分）

**计算步骤**：
1. 统计各灰度级像素个数 → 计算概率
2. 计算累计概率 CDF
3. 均衡化映射：s = round(CDF × (L-1))，L为灰度级数
4. 输出均衡化后图像

**真题示例**（A卷第4题）：
```
灰度值：  0   1   2   3   4   5
像素数：  4   5   3   6   3   4
概率：  0.16 0.20 0.12 0.24 0.12 0.16
累计：  0.16 0.36 0.48 0.72 0.84 1.00
映射(s×5): 1   2   2   4   4   5
```

### 3.2 图像插值 (Interpolation)（必考，约10分）

**最近邻插值 (Nearest Neighbor)**：
- 取离目标点最近的原始像素值
- P1=直接取最近点的值

**双线性插值 (Bilinear Interpolation)**：
- 用周围4个点加权平均
- 先水平方向两次线性插值，再垂直方向一次
- 结果更平滑但计算量大

**放大图像**：
- 例如2×2放大：每个像素变成2×2块
- 最近邻放大：直接复制

### 3.3 图像分割 (Image Segmentation)

**基本全局阈值法 (Basic Global Thresholding)** — 迭代算法步骤（必考简答）：

```
1. 选初始阈值T（通常取图像均值）
2. 用T分割：G1 = {像素>T}, G2 = {像素≤T}
3. 计算G1均值m1, G2均值m2
4. 新阈值 T_new = (m1+m2)/2
5. 重复直到|T_new - T| < 预设值
```

**Otsu方法**：
- 最优阈值选择，最大化类间方差 (between-class variance)
- 判断题："Otsu maximizes between-class variance" → **对**

**区域生长算法 (Region Growing)** 步骤（必考简答）：
1. Seeding（选种子点）
2. Selection of similarity criteria（选相似性准则）
3. Stopping rule（停止条件：没有更多像素满足条件，或满足先验知识如大小/形状）

**Hough变换**：
- 用于检测直线
- 判断题："Hough transform can detect straight lines" → **对**

## 第4天：图像压缩 + 形态学 + 彩色图像（约20%分值）

### 4.1 Huffman编码（必考计算大题，12分）

**编码步骤**：
1. 统计各灰度值的出现概率
2. 按概率排序（降序）
3. 反复合并最小的两个概率，构建二叉树
4. 从根到叶分配编码（左0右1或反之）
5. 概率大的分配短码，概率小的分配长码

**压缩指标计算**：
- 平均码长 Lavg = Σ(概率 × 码长)
- 压缩比 C = b_original / Lavg（原8bit÷平均码长）
- 相对数据冗余 R = 1 - 1/C

**真题示例**（A卷第8题答案）：
```
灰度值 1:000  2:0010  3:1  4:0111  5:01
Lavg = 2.15
C = 8/2.15 = 3.72
R = 1 - 1/3.72 = 0.73
```

### 4.2 形态学图像处理 (Morphological)

**基本操作**（会手算）：
- **膨胀 (Dilation)**：结构元素覆盖区域取MAX，扩大亮区域
- **腐蚀 (Erosion)**：结构元素覆盖区域取MIN，缩小亮区域
- **开操作 (Opening)**：先腐蚀后膨胀 = 平滑轮廓、消除小物体
- **闭操作 (Closing)**：先膨胀后腐蚀 = 填充小孔洞

**真题题型**：给原始二值图像和结构元素，手动计算膨胀/开操作结果

**开操作两大步骤**：
- Step 1: Erosion（腐蚀原始图像）
- Step 2: Dilation（对腐蚀结果膨胀）

### 4.3 彩色图像处理

**三种颜色模型**：
| 模型 | 用途 | 特点 |
|------|------|------|
| RGB | 彩色显示器 | 加法混色，硬件导向 |
| CMY/CMYK | 彩色打印 | 减法混色，RGB的补色 |
| HSI | 图像处理/人类视觉 | Hue(色调) Saturation(饱和度) Intensity(亮度) |

**RGB中**：
- Red = (1,0,0)，Green = (0,1,0)，Blue = (0,0,1)
- Cyan = (0,1,1)，Magenta = (1,0,1)，Yellow = (1,1,0)
- White = (1,1,1)，Black = (0,0,0)

**HSI模型**：
- H (Hue色调)：角度表示，0°红，120°绿，240°蓝
- S (Saturation饱和度)：到圆心的距离，0=灰色，1=纯色
- I (Intensity亮度)：垂直轴，下黑上白

**伪彩色处理 (Pseudocolor)**：
- 给灰度图像分配颜色，不是真正的彩色图像
- 判断题："可以给不同灰度值分配相同颜色" → **错**

**全彩色图像处理两种方法**：
1. 分别处理每个通道
2. 将像素作为向量整体处理

### 5.2 图像复原 (Image Restoration)

**与图像增强的区别**（常考判断）：
- 图像增强 (Enhancement)：主观过程 (subjective)，结果不能量化
- 图像复原 (Restoration)：客观过程 (objective)，可利用退化函数恢复

**退化模型**：
g(x,y) = h(x,y) * f(x,y) + n(x,y)
G(u,v) = H(u,v)·F(u,v) + N(u,v)

**逆滤波 (Inverse Filter)**：
F̂(u,v) = G(u,v)/H(u,v)（无噪声时完美恢复）

**维纳滤波 (Wiener Filter)**：
- 最小均方误差准则
- 当噪声为0时退化为逆滤波
- 实际中用常数K代替功率谱比值

### 易错提醒
1. **存储单位**：看清楚题目要的是 bits、bytes、KB 还是 MB
2. **滤波不处理边界**：3×3滤波时图像最外一圈不变
3. **Huffman编码不唯一**：合并时选哪两个小的可以不同，但平均码长一样
4. **直方图均衡化映射值要取整**：s = round(CDF × (L-1))
5. **双线性插值**：先水平后垂直，共3次线性插值
